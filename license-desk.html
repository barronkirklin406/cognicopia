License desk

This page makes the license keys that unlock Cognicopia for a facility. It is for the owner only. It runs in your web browser and cannot send anything anywhere: your secret key file stays on your computer.

1Make your license-making key (do this once)

This makes two things. A secret file that only you keep. It is the only thing that can make license keys. And one safe line that you give to Claude so the website can check your keys. The safe line can only check keys, never make them, so it is fine to share.

Your key was made. Your browser should have saved a file named cognicopia-license-private.pem. Look in your Downloads folder. If you cannot find it, press the button below to save it again.
Take care of that file.
  • Copy it somewhere safe right away: your password manager, or a USB stick kept in a safe place.
  • Never email it, paste it into a chat, or put it on the internet. Not even to Claude.
  • If it is lost, every license key has to be made again.

Copy this line and paste it into your message to Claude. It starts with PUBLIC_KEYS.

2Make a license key for a facility

Use this after someone pays by invoice, or when a card buyer needs their key made by hand.

The license keeps working for another 90 days after this date, even with no internet.

3Check a license key

Paste any license key to see whether this website accepts it, and what it says.
